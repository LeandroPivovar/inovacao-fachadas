# Inovação Fachadas em ACM - site institucional

Site one-page da **Inovação Fachadas em ACM**: fachadas em ACM, estruturas metálicas, lavagem, revitalização e manutenção de fachadas comerciais.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, como funciona, contato, FAQ)
styles.css   # estilos (grafite e cinza do logo, bronze de destaque, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # logo, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Antes de publicar

- **Cidade:** o perfil não mostra endereço. O DDD 41 é da região de Curitiba - PR, mas o site não cita cidade.
- **Telefone:** o número tem 8 dígitos depois do DDD, como aparece no perfil. Confirme se é o número completo.
- **Cores:** o logo é em tons de grafite e cinza. O bronze dos botões e destaques foi escolhido por mim; dá para trocar no topo do `styles.css`.
- **Logo:** `assets/logo-inovacao.png` foi recortado do print do perfil (cerca de 143px). Troque pelo arquivo original.
- **Fotos:** de banco de imagens. Fotos reais de fachadas entregues (antes e depois) são o que mais vende nesse ramo.
